Hak Pengguna & Penghapusan Data

Sesuai kebijakan Google Play, Anda berhak meminta penghapusan akun dan seluruh data pribadi yang terkait dengan aplikasi kami tanpa harus memasang kembali aplikasi.

Chat Saver, GPS Navigator, Morse Detector, Translator, Format Converter, Code Scanner, dan File Transfer tidak memiliki akun dan tidak menyimpan data pribadi di server kami. Datanya hanya ada di perangkat Anda dan dihapus dengan menghapus data aplikasi atau mencopotnya (lihat rincian di tiap aplikasi). Chat Saver bahkan dapat dihapus langsung dari dalam aplikasi.

Aplikasi kuis (dengan login Google)

  1. Kirim email ke karyakukreatif@gmail.com.
  2. Subjek: "Permohonan Penghapusan Data - [Nama Aplikasi]", misalnya Permohonan Penghapusan Data - Kuis Pengetahuan Umum.
  3. Cantumkan alamat email akun Google yang Anda pakai untuk login.

Data yang dihapus permanen: profil (nama, email, ID pengguna Google), seluruh riwayat skor, poin, dan progres permainan, serta catatan akun di database server kami.

Waktu proses: maksimal 7 hingga 14 hari kerja setelah permohonan diterima. Setelah itu data dihapus permanen dan tidak dapat dipulihkan.
